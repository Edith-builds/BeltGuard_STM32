# Bench commissioning and acceptance checks

1. With the motor electrically disabled, inspect supply rails, common ground, Nucleo power jumpers and sensor logic levels. Verify the physical emergency stop independently. Firmware has no motor output.
2. First boot with `BG_CALIBRATED=0`. Confirm UART packets/CRC/sequence. `rf_ok` must recognise a supported reader, `spi_errors` must stay flat. Bring a tag into the field; collect its complete `uid`. `uid_ms` indicates how old that read is. Board reset returns counters to zero.
3. Capture all four real UIDs and measured positive-direction phase offsets relative to the reader. Enter them in the configuration. Repeated observations of the same tag within a pass count once. UID values in the delivered config are examples only.
4. Measure encoder counts for one roller revolution and one complete belt revolution. Confirm sign and x4 convention; use belt travel rather than assumed roller diameter if there is slip. Fit independent phase windows; neighbouring windows must not overlap. Begin at low speed.
5. Empty/known-weight load calibration: average raw HX711 readings, calculate tare and counts/kg. Verify sign, saturation and stale/disconnected reporting. The expected DOUT rate is10 or80 SPS depending on module RATE wiring. Load is support reaction; do not claim measured belt tension.
6. Set calibration true and test no load / stopped / loaded running transitions. Vibration/mic health windows must be invalid when stopped or unloaded on node1. Diagnostic RFID passages still operate while moving unloaded. Node2 remote-gate mode deliberately leaves health eligibility to the laptop.
7. Verify actual INMP441 WS and SPI clocks with a logic analyser, microphone channel alignment and signed 24-bit conversion. Measure idle signal and controlled tone. Verify accelerometer gravity magnitude on each axis and known motion. Never connect an unconditioned piezo to an MCU ADC.
8. Measure worst-loop duration and FIFO/audio overruns with all sensors and UART active. Any increasing `fifo_gaps`/`mic_gaps` invalidates continuous-sampling assumptions. Optimise FIFO servicing, use a DMA SPI driver or reduce processing on MCU if needed. Watchdog reset recovery must be tested separately.
9. At each operating speed, run at least30 expected passes per tag intact. Then shield/remove one tag. Confirm only that tag's misses rise and the warning appears after the configured number of failed passages. Stop inside the RF window: no new passage should close until the encoder moves beyond it.
10. Test all-tags-missing, reader unplugged, changed antenna clearance, metallic interference, belt reverse, encoder disconnect and deliberate belt slip. An encoder disconnected while the belt runs can look stopped: this setup needs an independent motion reference to detect that fault. Never turn that apparent “stopped” state into a healthy-belt conclusion.
11. Compare intact belt/intact tag, intact belt/damaged tag, damaged belt/intact tag and damaged belt/damaged tag. RFID is a candidate health indicator whose causal link must be established, not assumed. Visual and other-sensor evidence are needed before a maintenance diagnosis.
12. Test laptop disconnect/reconnect: sequence gaps are visible; no old packets are replayed. Preserve host receive times and reset segments. The edge app must expire stale nodes and missing camera/thermal frames before computing BHI.
13. Test a seeded defect with measured ground truth, including fault-free passes. Report false alarms, recall, actual localisation error and timing. Do not substitute a literature benchmark or the existence of source code for these results.

RFID phase drift outside the configured read window produces `sync_errors`. Investigate slip, physical movement and scale; stop/recommission/reset deliberately. The code does not continuously move the reference origin to hide drift.
